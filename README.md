# landing_page_chuteira
Landing page de produto esportivo desenvolvida como exercício de HTML e CSS.
O projeto simula a página de detalhes de uma chuteira fictícia, com foco em layout responsivo, uso de Flexbox, tipografia personalizada e organização semântica do código.
Ideal para portfólio e demonstração de habilidades em front-end.

Principais recursos:

Estrutura semântica em HTML5
Layout moderno com Flexbox
Tipografia customizada com Google Fonts
Design responsivo básico
Seções de descrição, depoimento e chamada para ação
